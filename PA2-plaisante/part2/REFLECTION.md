# PA 2 Reflection

1. Approximately how much time did you spend on the final PA 2 submission?**

About 6 hours.

2. What were the most challenging portion(s) of the assignment?

The most challenging part was understanding the overall logic of how the game runs. I had to figure out how `Card`, `Hand`, `Tableau`, and `Plaisante` work together, such as how a card moves from `heldCards` to `selected` and then to `playArea`, and how a hand gets evaluated and scored once it is played.

3. What is one thing you have a better understanding of after completing this assignment and going through the class content?

I have a much more solid understanding of arrays and lists, and of calling methods. For example, I now know the difference between using `.length` for an array and `.size()` for a `List`. I also got a lot of practice writing small helper methods like `countValues()` and reusing them in other methods like `hasPair()` and `hasFullHouse()`.

4. Do you have any follow-up questions about concepts that you'd like to explore further?

I would like to learn more about UI design, like how the `Plaisante` class draws the game on screen, handles user input, and makes the interface look good.
